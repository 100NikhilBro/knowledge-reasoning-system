PEP: 604

Title: Allow writing union types as X | Y

Author: Philippe PRADOS, Maggie Moss

Status: Final

Type: Standards Track

Created: 28-Aug-2019

Python Version: 3.10

Abstract
========

This PEP proposes overloading the | operator on types to allow writing Union[X, Y] as X | Y, and allows it to appear in isinstance and issubclass calls. PEP 484 and PEP 526 propose a generic syntax to add typing to variables, parameters and function returns.

Motivation
==========

To describe a disjunction (union type), the user must use Union[X, Y]. The verbosity of this syntax does not help with type adoption. A more readable union syntax improves readability of type hints.

Rationale
=========

Inspired by Scala and Pike, this proposal adds operator type.__or__(). With this new operator, it is possible to write int | str instead of Union[int, str]. The existing typing.Union and | syntax should be equivalent. Optional values should be equivalent to the new union syntax as None | t equals Optional[t].
